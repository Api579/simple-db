# Ecommerce Database Project

A simple PHP + MySQL project for an online marketplace.

## Files

- `database_code.sql` - creates the database, tables, sample data and views
- `forms.php` - forms to add customers, vendors, products, orders and shipments
- `reports.php` - reports for customers, shipments, orders, categories and vendors

## How to Run

1. Import `database_code.sql` into MySQL (e.g. through phpMyAdmin).
2. Put `forms.php` and `reports.php` in your server folder (e.g. XAMPP's `htdocs`).
3. If your MySQL login isn't `root` with no password, update it at the top of both PHP files.
4. Open `forms.php` or `reports.php` in your browser.
