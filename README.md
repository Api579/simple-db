# Sample Ecommerce Database 

Simple PHP & MySQL project: small database for an online marketplace on MySQL accessed using PHP scripts.

## Files

- `database_code.sql` - creates database, tables, sample data, views
- `forms.php` - forms for adding customers, vendors, products, orders and shipments
- `reports.php` - reports for outputting customers, shipments, orders, categories and vendors

## How to Run

1. Import `database_code.sql` into MySQL (for example, using phpMyAdmin).
2. Put `forms.php` and `reports.php` in server folder (for example, XAMPP's `htdocs`).
3. If MySQL login isn't `root` without any password, then update at top of PHP files.
4. Open `forms.php` or `reports.php` in browser (example, with XAMPP).
